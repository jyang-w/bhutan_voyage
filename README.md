# 🇧🇹 Bhutan Voyage

A Tkinter-based desktop application for exploring destinations in Bhutan, booking trips, and managing payments.

## ✨ Features
- 🏔️ Browse destinations across Bhutan's districts
- 📅 Book trips and manage itineraries
- 💰 Dual payment system — Bhutanese & International
- 🔐 User accounts and admin dashboard
- 🖼️ Beautiful destination images

## 🛠️ How to Run

1. **Clone or download** this repository
2. **Install Python** (3.8 or higher recommended)
3. **Run the main file:**
```bash
python main.py
